# Eudelay

Eudelay will be a signal delay built on Euclidean rhythm, the concept of spacing a number of events as evenly as possible over time.

## Direct Controls

* CV1 : delay time fine adjustment
* Knob 1 : taps : number of delay line taps. Knob centre position corresponding to NSteps/2
* CV2 : feedback from sum of tapped values, 0-100%
* Knob 2 : tap offset : number of steps between the start and the first tap. Values 0-NSteps

## Menu UI Controls

* Steps (NSteps) : overall number of steps in the rhythm. Values 2-16, default 8
* BPM : delay time will be aligned to this. Values 80-200, default 140
* Scale : ratio of delay time to BPM
